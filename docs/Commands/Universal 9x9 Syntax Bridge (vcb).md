# 🌉 Universal 9x9 Syntax Bridge (`vcb`)

The **Universal 9x9 Syntax Bridge** (`bridge_9x9_syntax.py`) provides invariant-preserving syntactic translation between external simulation schemas (such as Foundry or CrateEngine) and ViperCrest's native 9x9 observation schema.

---

## ⚙️ Core Functions

- **Bidirectional Invariant Mapping**: Normalizes heterogenous external JSON trees into 9x9 canonical arrays without data loss.
- **Verification Rule Projection**: Maps external property assertions to F1–F9 verification tiers.
- **Syntactic Linting**: Validates that all incoming structures satisfy the formal 9x9 invariant invariants before passing into the matrix engine.

---

## 💻 Invocation

```cmd
vcb --help
vcb --input fixtures\example.json
```
